Expense Data Analysis Project
Project Overview:
In this project, I organized and analyzed personal expense data using Excel and SQL. The main objective was to understand spending patterns and apply basic data analytics skills to real-world data.
Tools Used:
Microsoft Excel: Used for creating and arranging the raw dataset in CSV format.
SQL: Used for database table creation, data insertion, and running analytical queries.
GitHub: Used for version control and sharing the project files.
Repository Files:
Expense-data.csv: Contains the raw transaction data.
queries.sql: Contains SQL statements including CREATE TABLE, INSERT INTO, GROUP BY, and ORDER BY queries.
Key Operations Performed:
Created a database table with an appropriate schema to store expense data.
Inserted transaction records into the table.
Used GROUP BY to calculate total spending by category.
Used ORDER BY to sort expenses and identify the highest expenditures.
